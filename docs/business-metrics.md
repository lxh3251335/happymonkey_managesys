# 经营总览口径

| 指标 | 口径 |
|---|---|
| 合同额 | 已确认订单；或已填合同号、报价为“历史/已出具”的门店订单（待确认合同）。每个门店只取一份报价：已确认的那份，否则取最新版本。 |
| 月份 | 合同额按项目下单日期归月；历史记录缺下单日期时记为“未知”。到账额按收款日期归月。 |
| 到账额 | 收款减退款（含按合同整笔登记后分摊到门店的流水）。 |
| 回款率 | 到账额 ÷ 合同额。 |
| 应收余额 / 账龄 | 仅已确认订单：确认金额 − 到账额；按应收截止日分为未到期、逾期 1-30、31-60、61-90、90 天以上。 |
| 在手订单 | 合同额中发货状态不是“已发货”的门店（制作中、未登记）。 |
| 毛利 / 毛利率 | 只统计报价与成本都完整的明细行；“成本覆盖”= 参与计算的金额 ÷ 合同额。 |
| 业务：品牌 | 项目品牌：小象、快乐猴、其他。 |
| 业务：产品线 | 按品名归类：物联网电控箱、配电柜、软件及平台、配电箱（含各类电箱）、其他。到账额按门店订单内明细金额比例分摊。 |
| 客户集中度 | 第一大客户、前三大客户的合同额占比。 |

## 按合同登记回款

1. 回款与应收 → 合同台账：对“待确认”的合同点“确认应收”，填写应收截止日。该合同下所有门店订单变为已确认。
2. 点“登记回款”，按银行流水整笔填写。系统按各门店剩余应收比例分摊（最大余数法，精确到分），分摊流水号为“凭证号#序号”。
3. 错误收款通过“退款”关联原合同收款冲正，按原分摊比例退回，不修改原流水。

合同号与发货状态在项目台账中维护。早期导入只把它们写在项目备注里，系统启动时会自动补写到结构化字段。
