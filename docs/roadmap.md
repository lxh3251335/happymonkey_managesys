# V0.1 验收与迭代

## 当前交付

- 项目台账，客户归属、品牌、日期、备注及云智冷项目 ID。
- 客户、供应商和标准产品资料新增与查询。
- 报价草稿、出具、复制为新版本、人工确认订单、客户报价单打印/PDF。
- 两种利润率、内部成本、缺失值提示、按客户及品牌汇总。
- 供应商有效报价、税率、含税运费、起订量、交期与同产品比价。
- 客户部分回款、退款、应收余额和逾期标记。
- 账户登录、密码修改、内部用户创建、四种角色及操作审计。
- 可复现的本轮历史资料导入、行级来源、隔离明细及导入幂等。
- 本机启停脚本、Docker 配置、数据库迁移、CI 配置和业务测试。

本轮后端测试覆盖：舍入及零分母、缺失成本、状态流转、同项目重复应收、客户版本无成本字段、回款超额、重复凭证、关联退款、会话与权限、CSRF、供应商税运费及起订量、导入幂等及空成本。

浏览器验证包括登录和七个业务页面、桌面与平板布局；独立测试库中实际操作创建报价、出具、对客打印、确认订单、登记部分回款和供应商到货比价。测试报价 2,000 元，回款 500 元后剩余应收 1,500 元；供应商含税单价 600 元、数量 2、运费 20 元时到货总价为 1,220 元。对客页面及接口不包含成本、利润字段。截图保存在本机 artifacts 中，不纳入源码仓库。

## V0.2 增补

- 报价模板：公司抬头、地址、联系人、收款账户、纳税人识别号、标准条款和页脚；可设默认、停用。报价出具时快照模板内容，之后修改模板不影响已出具报价单。
- 合同附件：按合同上传合同扫描件、盖章报价单、送货签收、发票等（PDF/JPG/PNG/Word/Excel/OFD，单个 20 MB）。校验文件头与重复文件，删除为软删除，上传、下载、删除均记审计。
- 管理员资料维护：客户/供应商、标准产品可编辑（已保存报价明细保留原品名规格）；用户可改显示名称、角色、启用状态并重置密码。停用或改角色后已登录会话立即失效；不能停用或降级自己，系统至少保留一个启用的管理员。

## 当前限制

本版还没有公网地址；生产 PostgreSQL / Docker 验证等待可用环境。云智冷目前只有关联 ID 字段。在线 Excel 导入、Excel 报价下载、发票核销、采购订单和供应商付款尚未实现。对客输出目前通过浏览器打印/PDF。

当前用户角色为固定角色，已支持账户停用和密码重置，尚未提供细粒度菜单/项目授权或组织隔离。系统无客户门户，不应给外部客户分配内部只读账号。所有内部角色可看成本。

## 建议下一阶段

### 业务确认与完整数据

核对历史项目、不同名称的同一门店、税口径和缺成本记录；补录客户实际回款。在“报价模板”中录入正式公司抬头、收款账户和报价条款；确认运输/安装等费用口径。为已签合同补传附件。

### 正式上线

在实际 PostgreSQL 上运行 CI 和业务回归；配置云服务器、域名与 HTTPS；完成备份恢复演练。补齐更细粒度授权；附件目录纳入备份；设计登录异常告警及审计留存。

### 规模与外部协同

实现服务端分页、索引和大数据量聚合；增加标准成本分项和审批流程；加入采购订单、供应商付款与发票核销。按云智冷正式 API 文档实现项目同步和异常处理；需要多企业 SaaS 时再引入明确的租户边界和集中会话。

每阶段按可验收的业务流程迭代，保留迁移与计算版本，避免直接覆盖历史报价或账务。
